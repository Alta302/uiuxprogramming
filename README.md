# 신선노트 (FreshNote)
> 냉장고 속 식재료의 소비기한을 놓치지 않도록 미리 챙겨주는 스마트 알림 서비스

# 2주차 구조 변경 및 구현 이유
- 사용자가 서비스 정보를 직관적으로 탐색할 수 있도록 시맨틱 영역(header, nav, main, section, footer)으로 재구성했습니다.
- 정보 이해 순서를 '소개 -> 주요 기능 -> 이용 방법 -> 알림 신청'으로 정의했습니다.
- 주요 기능은 병렬 목록(ul), 이용 방법은 단계적 절차(ol)로 구분했습니다.
- nav 링크와 각 section id를 연결해 페이지 내부 이동 경로를 마련했습니다.

# 3주차 CSS 수정 기록

## 수정한 내용
주요 기능 세 가지를 담은 `.feature-list` 요소에
`display: flex`와 `gap: 20px` 속성을 추가하여 가로 배열로 변경했습니다.

## 수정 이유
신선노트의 핵심 기능들이 개별적으로 떨어져 보이지 않고 하나의 그룹처럼 보이게 묶어주어,
사용자가 서비스의 장점을 한눈에 파악하기 쉽게 UI를 개선했습니다.

# 4주차 반응형 수정 기록

## 확인한 문제
390px에서 메뉴와 기능 카드, 알림 신청 폼의 가로 배치가 좁아져 읽기와 조작이 불편했습니다.

## 수정한 내용
768px 이하에서 메뉴·기능 카드·알림 신청 폼을 한 열로 바꾸고, 기능 카드에는 자동 Grid를 적용했습니다.
또한 콘텐츠와 이미지가 화면 너비에 맞게 줄어들도록 width와 max-width를 함께 적용했습니다.

## 달라진 점
390px에서도 가로 스크롤 없이 내용을 읽고 이메일 입력과 알림 신청 버튼을 사용할 수 있습니다.

# 5주차 JavaScript 인터랙션 구현 기록

## 구현한 기능
- `script.js`를 `index.html`의 `</body>` 바로 앞에 연결했습니다.
- 알림 신청 폼에 `submit` 이벤트를 연결하고 `event.preventDefault()`로 새로고침을 방지했습니다.
- 이메일을 비워두거나 잘못 입력하면 안내 문구와 오류 배경색이 표시됩니다.
- 올바른 이메일을 입력하면 이메일 주소를 포함한 완료 문구와 성공 배경색이 표시되고, 버튼이 `신청 완료`로 변경되어 비활성화됩니다.
- 입력한 이메일은 현재 브라우저 화면에서만 처리합니다. 실제 서버 저장·이메일 전송은 지원하지 않습니다.

## 피드백 반영: 이메일 주소 수정
- 신청 완료 후 `주소 수정` 버튼을 표시합니다.
- 버튼을 누르면 `isSubscribed`와 입력창의 `readOnly`를 `false`로 되돌리고, 신청 버튼을 활성화하며 문구를 `소비기한 알림 신청하기`로 복원합니다.
- 기존 주소를 유지하고 입력창으로 포커스를 이동해 바로 수정할 수 있도록 합니다. 성공·오류 스타일은 지우고 재신청 안내를 표시합니다.
- 수정 후에도 빈 값과 이메일 형식을 다시 검사하며, 재신청이 완료되면 입력창을 잠그고 `주소 수정` 버튼을 다시 표시합니다.

# 6주차 이벤트 처리와 동적 UI 구현 기록

## 구현한 이벤트와 화면 변화

| 이벤트 | 사용자 행동 | 함께 바뀌는 화면 상태 |
| --- | --- | --- |
| `input` | 식재료 이름 입력·삭제 (최대 10자) | 글자 수·입력 안내 문구와 배경색 갱신, 이름·옵션 조건에 따라 미리보기 버튼 활성화 |
| `change` | 소비기한 3일 전 알림 옵션 체크·해제 | 준비 안내 문구와 `is-ready` 스타일 변경, 미리보기 버튼 활성·비활성 전환 |
| `click` | 알림 미리보기 버튼 클릭 | 식재료 이름을 포함한 예시 안내와 `is-success` 스타일 표시, 버튼을 `미리보기 완료`로 변경하고 비활성화 |
| `click` | 주요 기능 탭 클릭 | 선택된 탭의 색상과 `aria-selected` 갱신, 연결된 콘텐츠만 표시 |

- 이름이나 옵션을 변경하면 완료 상태를 초기화하고 다시 미리 볼 수 있습니다. 공백만 입력한 경우에는 실행할 수 없습니다.
- 식재료 이름은 `textContent`로 표시합니다. 미리보기는 화면 시연이며 실제 알림 예약·서버 저장·이메일 발송은 하지 않습니다.
- 5주차 이메일 신청의 빈 값·형식 검사와 신청 완료 후 주소 수정·재신청 동작을 유지했습니다.

## 주요 기능 탭

- `소비기한 관리`, `만료 전 알림`, `추천 레시피`의 세 탭을 구현했습니다.
- `querySelectorAll`과 `forEach`로 각 탭의 이벤트를 연결하고, `data-target`으로 해당 패널을 찾습니다.
- 선택된 탭은 `is-active`와 `aria-selected="true"`를 적용하고, 다른 패널은 `hidden`으로 숨깁니다.
- 최초에는 소비기한 관리 탭만 선택됩니다. 탭과 패널은 `aria-controls`·`aria-labelledby`로 연결했습니다.
- Tab 키로 선택된 탭과 콘텐츠에 접근하고, 좌우 방향키·Home·End로 탭을 전환할 수 있습니다. 버튼은 Enter·Space로 조작할 수 있습니다.
- 768px 이하에서는 탭을 세로로 배치합니다.
