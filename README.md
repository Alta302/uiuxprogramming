# 신선노트 (FreshNote)

냉장고 속 식재료의 소비기한을 확인하고, 먼저 먹을 재료를 챙길 수 있도록 돕는 서비스입니다.

## 사용자와 목표

- 주요 사용자: 혼자 살면서 식재료의 소비기한을 자주 놓치는 사람
- 사용자 목표: 식재료의 소비기한과 알림 시점을 정하고 등록 내용을 확인한다.
- 핵심 행동: 식재료 이름·소비기한 입력, 알림 시점 선택, 내용 확인 후 등록 완료
- 완료 조건: 완료 버튼을 누르면 식재료·소비기한·알림 시점·알림 예정일이 완료 화면에 표시된다.

현재는 화면 시연으로, 실제 서버 저장이나 알림 발송은 하지 않습니다.

## 사용자 흐름

**시작 → 입력 → 선택 → 확인 → 완료**의 5단계로 구성했습니다.

1. 시작: ‘식재료 등록’ 메뉴 또는 미리보기 아래 링크로 이동해 ‘식재료 등록 시작’을 누릅니다.
2. 입력: 식재료 이름(1~20자)과 오늘 또는 이후의 소비기한을 입력합니다.
3. 선택: 소비기한 3일 전·1일 전·당일 중 알림 시점을 선택합니다.
4. 확인: 입력한 식재료, 소비기한, 알림 시점과 알림 예정일을 확인합니다. 이전 버튼으로 돌아가 수정할 수 있습니다.
5. 완료: ‘확인한 내용으로 등록 시연 완료’를 누릅니다. 다른 식재료를 입력하려면 ‘다시 시작’을 누릅니다.

## 인터랙션 시나리오

| 행동 | 이벤트 | 조건 | 화면 반응 | 다음 상태 |
| --- | --- | --- | --- | --- |
| 등록 시작 | click | 시작 화면 | 식재료 입력 화면 표시 | 입력 |
| 입력 후 다음 | submit | 이름이 비어 있거나 공백뿐임 | 이름 입력 안내, 해당 입력창으로 이동 | 입력 유지 |
| 입력 후 다음 | submit | 날짜가 없거나 지난 날짜임 | 오늘 또는 이후 날짜를 선택하도록 안내 | 입력 유지 |
| 입력 후 다음 | submit | 이름·소비기한이 올바름 | 알림 시점 선택 화면 표시 | 선택 |
| 선택 후 다음 | submit | 알림 시점을 선택하지 않음 | 선택 방법 안내 | 선택 유지 |
| 선택 후 다음 | submit | 알림 예정일이 이미 지남 | 더 가까운 시점이나 당일을 선택하도록 안내 | 선택 유지 |
| 선택 후 다음 | submit | 입력과 선택이 올바름 | 입력값과 선택값을 확인 화면에 표시 | 확인 |
| 이전 | click | 입력·선택·확인 화면 | 값을 유지한 채 앞 단계 표시 | 이전 단계 |
| 값 수정 | input / change | 입력 또는 선택을 바꿈 | 해당 항목의 오류 안내 해제, 다음을 누르면 다시 검사 | 현재 단계 |
| 수정 후 다음 | submit | 수정한 값이 올바름 | 바뀐 내용으로 확인 화면 갱신 | 확인 |
| 등록 완료 | click | 입력과 선택이 올바름 | 최종 내용과 완료 안내 표시 | 완료 |
| 등록 완료 | click | 날짜가 바뀌어 소비기한이나 알림 예정일이 지남 | 해당 단계로 돌아가 수정 안내 | 입력 또는 선택 |
| 다시 시작 | click | 진행 중 또는 완료 화면 | 입력·선택·오류·확인 내용·완료 내용·진행 상태 초기화 | 시작 |
