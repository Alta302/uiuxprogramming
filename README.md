# 신선노트 (FreshNote)

냉장고 속 식재료의 소비기한을 확인하고, 먼저 먹을 재료를 챙길 수 있도록 돕는 서비스입니다.

## 사용자와 목표

- 주요 사용자: 혼자 살면서 식재료의 소비기한을 자주 놓치는 사람
- 사용자 목표: 소비기한이 가까운 식재료부터 확인하고 먹은 재료를 구분한다.
- 주요 행동: 식재료 등록, 보관 목록 확인, 소비 완료 처리, 잘못 처리한 항목 되돌리기

## 중간고사에서 추가한 기능

7주차의 등록 완료 화면에 ‘보관 목록에 담기’를 연결하고, 담은 식재료를 소비기한 순으로 확인하며 ‘소비 완료’로 처리하는 기능을 추가했습니다. 잘못 처리한 식재료는 ‘보관 목록으로 되돌리기’로 복구할 수 있습니다.

## 사용자 흐름

**식재료 등록(시작 → 입력 → 선택 → 확인 → 완료) → 보관 목록에 담기 → 소비 완료**

- 보관 목록에는 식재료 이름, 소비기한, 알림 시점·예정일, 남은 기한이 표시됩니다.
- ‘소비 완료’를 누르면 해당 재료가 완료 목록으로 이동하고 각 목록의 개수가 바뀝니다.
- 잘못 눌렀다면 완료 목록에서 되돌릴 수 있습니다. 식재료 정보는 유지됩니다.
- 다른 재료를 등록하려면 등록 화면의 ‘다시 시작’을 누릅니다. 입력값은 초기화되지만 이미 담은 목록은 유지됩니다.

목록은 현재 화면에서만 관리되며 새로고침하면 초기화됩니다. 서버 저장이나 실제 알림 발송은 하지 않습니다.

## 새 기능의 시나리오

| 사용자 행동 | 확인할 조건 | 성공 반응 | 다른 분기의 반응 | 다음 행동 |
| --- | --- | --- | --- | --- |
| 보관 목록에 담기 | 등록을 완료했고 아직 담지 않은 식재료인가? | 완료한 이름·날짜·알림값으로 목록 추가, 개수 갱신 | 같은 등록 건의 추가 버튼을 비활성화해 중복 추가 방지 | 소비 여부 관리 또는 다른 재료 등록 |
| 보관 목록 확인 | 보관 중인 식재료가 있는가? | 소비기한이 가까운 순서로 표시 | 처음에는 등록 방법 안내, 모두 소비했으면 등록·되돌리기 안내 | 등록하거나 소비 완료 처리 |
| 소비 완료 | 보관 중인 식재료인가? | 해당 재료만 완료 목록으로 이동, 상태·개수·완료 안내 갱신 | 잘못 처리한 경우 되돌리기 버튼 제공 | 다른 재료 확인 또는 되돌리기 |
| 보관 목록으로 되돌리기 | 소비 완료한 식재료인가? | 원래 정보로 보관 목록 복구, 기한 순서·개수·안내 갱신 | 소비 완료한 재료가 없으면 목록에 안내 표시 | 보관 목록 확인 |
| 다른 재료 등록 | 기존 등록을 다시 시작했는가? | 입력값을 비우고 새 등록 진행, 기존 목록 유지 | 입력·선택 누락이나 지난 날짜는 해당 단계에서 수정 안내 | 수정 후 등록 완료·목록 추가 |

목록의 소비 완료·되돌리기는 버튼 클릭으로 처리합니다. 새 입력을 요구하지 않으며, 등록에 필요한 필수값 검사는 기존 흐름에서 수행합니다.
